# Clients
(*Clients*)

## Overview

### Available Operations

* [List](#list) - List clients

## List

Retrieve a list of all clients linked to your account.

The results are paginated.

### Example Usage

<!-- UsageSnippet language="csharp" operationID="list-clients" method="get" path="/clients" -->
```csharp
using Mollie;
using Mollie.Models.Components;

var sdk = new Client(security: new Security() {
    ApiKey = "<YOUR_BEARER_TOKEN_HERE>",
});

var res = await sdk.Clients.ListAsync(
    embed: "organization",
    fromP: "org_12345678",
    limit: 50
);

// handle response
```

## Get

    ApiKey = "<YOUR_BEARER_TOKEN_HERE>",
});

    id: "org_12345678",
