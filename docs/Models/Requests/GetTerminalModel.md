# GetTerminalModel

The model of the terminal. For example for a PAX A920, this field's value will be `A920`.


## Values

| Name      | Value     |
| --------- | --------- |
| `A35`     | A35       |
| `A77`     | A77       |
| `A920`    | A920      |
| `A920Pro` | A920Pro   |
| `Im30`    | IM30      |
| `Tap`     | Tap       |
