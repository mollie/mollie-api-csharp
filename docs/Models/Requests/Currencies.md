# Currencies

Provides the currencies to retrieve the settlements. It accepts multiple currencies in a comma-separated format.


## Values

| Name  | Value |
| ----- | ----- |
| `Eur` | EUR   |
| `Gbp` | GBP   |
| `Chf` | CHF   |
| `Dkk` | DKK   |
| `Nok` | NOK   |
| `Pln` | PLN   |
| `Sek` | SEK   |
| `Usd` | USD   |
| `Czk` | CZK   |
| `Huf` | HUF   |
| `Aud` | AUD   |
| `Cad` | CAD   |
