# ListAllSubscriptionsInterval

Interval to wait between payments, for example `1 month` or `14 days`.

The maximum interval is one year (`12 months`, `52 weeks`, or `365 days`).


## Values

| Name              | Value             |
| ----------------- | ----------------- |
| `DotDotDotDays`   | ... days          |
| `DotDotDotWeeks`  | ... weeks         |
| `DotDotDotMonths` | ... months        |
